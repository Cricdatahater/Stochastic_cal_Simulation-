# Project
In this project, I try to simulate the basic fundamentals of Stochastic Calculus such as Ito's Lemma and Integral. This project also uses Monte Carlo Simulation to confirm the said theorems. This projects uses several topics from finance such as Black Scholes Option Pricing, Returns and Realized Volatility of a stock etc. 
Through the means of this project I portray my knowledge of the subject of Stochastic Calculus, Simulation and Financial Modelling.
